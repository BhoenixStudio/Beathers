# Beathers

[![Version](https://img.shields.io/npm/v/beathers.svg)](https://www.npmjs.com/package/beathers)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](https://opensource.org/licenses/MIT)

## Description

Beather Library is a comprehensive collection of SCSS mixins, variables, and utility classes designed to streamline and enhance your SCSS development workflow.
It provides reusable components, responsive grids, typography helpers, and more, allowing you to quickly build responsive and visually appealing web applications.

## Documentation

For detailed information on how to use the Beathers Library, consult the [official documentation](https://beathers.bhoenixstudio.com).
The documentation provides comprehensive guides, usage examples, and detailed explanations of all available mixins, variables, and utility classes.

## Installation

Install the package using npm:

```shell
npm install beathers
yarn add beathers
```

Feel free to refer to the [documentation](https://beathers.bhoenixstudio.com) for more usage examples and detailed explanations of all available features in the Beathers Library.
